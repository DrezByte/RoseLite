Every non-gear drop model in the game, enlarged to 2.5x, so loot is easy to spot on a busy floor. 1754 items across 41 models. Weapons and armour are left alone — they're already big and distinctive.

The meshes are generated straight from the stock game assets: only the vertex positions are scaled, so the texture, the shading, the drop rate and the pickup radius are all the originals. Nothing is hand-modelled, and nothing is overwritten — disabling a switch deletes the copies again.

Each model gets its own switch, so you can enlarge Lisent and King Effigies and leave everything else alone. One model is shared by many items, though, so a switch enlarges everything that drops as that shape — the item counts below say how many. Relaunch the game after changing a switch. If you also install Larger Drops - Huge, whichever you enable last wins, and disabling it restores the other.
