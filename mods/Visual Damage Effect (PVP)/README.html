Converts the Stun, Mute and Sleep status effects into big readable text (STUNNED, MUTEEEE, SLEEEEP) — for PvP enjoyers who need to see crowd control at a glance.

Files

  • _fainting_01 / _mute_01 / _sleep_01 .eft — effect definitions
  • _STUNNED_01 / _MUTEEEE_01 / _SLEEEEP_01 .ptl — particle scripts
  • _stunned_01 / _mute_01 / _sleep_01 .dds — text textures
