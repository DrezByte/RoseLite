# Custom alert sounds

Drop audio files in this folder and they show up in every sound picker in the
panel (Monster Tracker, loot plugin drop alerts, …), listed under **Custom**
below the built-in ones.

- Formats: `.mp3`, `.ogg`, `.wav`, `.m4a`, `.flac`, `.webm`
- The file name (without extension) is the name shown in the picker.
- Keep them short — they're alerts, not music.
- The folder is scanned at startup: restart RoseLite after adding files.

The built-in sounds (Ping, Chime, Coin, Alarm, Bell, Thud) are generated in
code and need no files here.
