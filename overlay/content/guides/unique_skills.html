Unique Skill List

In addition to the job class skills, there are also some unique skills in ROSE. Some of these skill books can be found in the Valor and Honor Shops; some are possible monster drops and some are rewards for killing the boss in a dungeon. These skills have prerequisite skill requirements and job class requirements. Remember to check whether you have the required prerequisite skill(s) before buying a skill from Honor or Valor.

Dungeon abbreviations: CoU = Cave of Ulvrick, HoO = Halls of Oblivion, SoD = Sea of Dawn, SC = Sikuku Catacombs.

IMPORTANT: The unique skills are all consumables and you consume them when you activate them. Be careful with the Unique Retraining Skill (the reset skill): if you reset a unique skill to get the skill points back, you'll need to get the skill book again if you later want it back.
