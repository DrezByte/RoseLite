There are several shortcuts and key combination to navigate more easily ingame.

You will be clicking less and pressing keys more often. 

The shortcuts include but not limited to the followings (I will update this post if there are other shortcuts brought to the game): 

+----+------------------------------+------------------------------------------------------+
| No |        Keys/Shortcuts        |                       Actions                        |
+----+------------------------------+------------------------------------------------------+
|  1 | /                            | Toggle run/walk                                      |
|  2 | Tab                          | Target/switch enemy                                  |
|  3 | T                            | Loot drops                                           |
|  4 | Z                            | Sit                                                  |
|  5 | I                            | Inventory                                            |
|  6 | C                            | Character                                            |
|  7 | K                            | Skills                                               |
|  8 | J                            | Quests                                               |
|  9 | N                            | Clan                                                 |
| 10 | M                            | Maps                                                 |
| 11 | H                            | Group                                                |
| 12 | G                            | Game Arena                                           |
| 13 | B                            | Item Mall                                            |
| 14 | O                            | Community                                            |
| 15 | Y                            | Game Options                                         |
| 16 | F1                           | Target yourself (normal mode)                        |
| 17 | F2                           | Target player (normal mode)                          |
| 18 | F3                           | Target player (reversed order) (normal mode)         |
| 19 | Alt (Hold)                   | Toggle show drop items                               |
| 20 | Esc                          | System Menu                                          |
| 21 | Space                        | Jump                                                 |
| 22 | WASD                         | Move around                                          |
| 23 | Middle mouse                 | Run forward                                          |
| 24 | Alt + U                      | Hide UI                                              |
| 25 | Hold Shift + left click      | Quickly send items to storage or NPC buy/sell window |
| 26 | Hold Shift + left click      | Add custom amount of stats (Character window)        |
| 27 | Hold Alt + left click on NPC | Interact with NPC even if blocked by players         |
| 28 | Shift + F1 to F3             | Switch among hotbar profiles                         |
+----+------------------------------+------------------------------------------------------+
